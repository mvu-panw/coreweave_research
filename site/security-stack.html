The three named incumbents

Cisco Account team

What we can see publicly:

  • Network operations run on Cisco and Juniper. "Cisco IOS and/or Juniper JunOS" is a listed requirement in Data Center Technician and Manager postings at Cheyenne WY, Plano TX, Afton TX, Chester VA, Dalton GA, Douglasville GA, Elk Grove IL, Ellendale ND, Marble NC, Miami FL and Sandusky OH. Confirmed example
  • Cisco is a CoreWeave shareholder. It joined the $650M secondary share sale in late 2024 at a reported $23B valuation. Reported Register
  • CoreWeave's physical-security WIDS platform (Bastille) is integrated with "Axis, Splunk, Cisco, and Lenel". Confirmed job

What we don't know: which Cisco security products are deployed: Secure Firewall (FTD/ASA), Firewall Management Center, ISE, Duo, Umbrella or Secure Access. No public posting names one. The tenant fabric is NVIDIA DPU and EVPN, not Cisco, so the Cisco firewalls most likely sit at the DC and PoP edge and in corporate. Inferred

Watch: Cisco's Hybrid Mesh Firewall now extends into NVIDIA BlueField DPUs under "Cisco Secure AI Factory with NVIDIA". CoreWeave's own Nimbus software already owns those DPUs. Reported Techzine

PANW stance: compete. Lead with threat-prevention-on throughput at the edge and with greenfield OT. positioning →

CrowdStrike Account team

Deepest-entrenched vendor on the list.

  • Built into the product: "CKS clusters include CrowdStrike by default for endpoint protection." Confirmed security architecture
  • Customer since at least 2023: the Falcon sensor runs on every Kubernetes node, alongside Falcon Cloud Security, Insight (EDR), OverWatch and Spotlight. The case study cites zero performance impact in the PoC. Reported case study
  • Partner and customer both ways (November 2025): CoreWeave offers Falcon Cloud Security, OverWatch and Falcon Complete MDR to its own tenants, and CoreWeave hosts training and inference for CrowdStrike's SafeMind models. CrowdStrike is also a featured member of the CoreWeave Partner Network. release
  • Vulnerability management postings list "Wiz, Rapid7, CrowdStrike" together with Tines and Jira. Confirmed job
  • Gap: Bare Metal as a Service nodes get "no CoreWeave in-band agent", so there is no Falcon by default on BMaaS. Confirmed BMaaS

PANW stance: don't attack the endpoint. CrowdStrike is a revenue partner and a customer of CoreWeave, so an EDR displacement fight would be political and unwinnable now. Complement it instead: put Cortex XSIAM over Falcon telemetry plus network and DPU data, and fill the network layer Falcon doesn't cover. Inferred

Teleport Account team

  • Infrastructure access plane for engineers: Senior Security Production Engineer postings require "experience managing and operating Teleport for infrastructure access control". Reported posting (mirror)
  • Infrastructure Security postings describe "just-in-time access systems and zero-trust infrastructure", which matches Teleport's role: certificate-based SSH, Kubernetes, database and app access with session recording. Reported posting (mirror)
  • Teleport isn't named in the current Greenhouse snapshot (October 2026), so these postings are older. It is still a running tool and not a new purchase. Inferred
  • Teleport covers engineers reaching servers and clusters. Who covers contractors and DC technicians at 20+ sites, OT vendor remote access, and SaaS and web access is an open question.

PANW stance: coexist, then expand around it. Leave engineer SSH and Kubernetes access on Teleport. Position Prisma Access (ZTNA 2.0) and Prisma Access Browser for field technicians, contractors and OT vendors. Treat PANW identity security (CyberArk) as the long-term privileged-access consolidation conversation, with the identity overlay. Inferred
