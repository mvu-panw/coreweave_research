# Deploy vector databases on CKS

> Deploy CWDB with pgvector, Milvus, and Dragonfly on CKS for AI and ML applications

These tutorials explain how to deploy vector databases on CoreWeave Kubernetes Service (CKS). Vector databases are optimized to store and query high-dimensional vectors. They're ideal for applications such as recommendation systems, image retrieval, and natural language processing.

## Available tutorials

The following tutorials are available:

* [CWDB with pgvector](https://docs.coreweave.com/products/cks/tutorials/deploy-vector-databases-on-cks/pgvector.md): Managed PostgreSQL with vector storage and similarity search.
* [Milvus](https://docs.coreweave.com/products/cks/tutorials/deploy-vector-databases-on-cks/milvus.md): An open source vector database built for GenAI applications.
* [Dragonfly](https://docs.coreweave.com/products/cks/tutorials/deploy-vector-databases-on-cks/dragonfly.md): An open source vector database built for GenAI applications.
