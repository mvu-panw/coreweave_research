# Deploy Anyscale on CKS

> Learn how to deploy Anyscale on CoreWeave Kubernetes Service

[Anyscale](https://www.anyscale.com/) is a managed platform for deploying and scaling [Ray](https://docs.ray.io/en/latest/)-based distributed AI and ML workloads. Anyscale runs on top of CKS using the Anyscale operator, which connects to the Anyscale control plane and manages Ray clusters on your behalf. This setup lets you use Anyscale's full suite of tools, workspaces, jobs, services, and datasets, while your compute runs on CoreWeave infrastructure. Anyscale also integrates with CoreWeave AI Object Storage.

For the full deployment tutorial, see [Deploy Anyscale on CoreWeave](https://docs.anyscale.com/k8s/coreweave/) in the Anyscale documentation.
