# Billing

> Learn how to manage your billing in the Cloud Console

Monitoring your usage and costs helps you understand and manage your CoreWeave spending.

If you administer CoreWeave Infrastructure and Forge together, see [CoreWeave Infrastructure and Forge billing](https://docs.coreweave.com/billing/coreweave-and-forge-billing.md) for which types of charges belong in which billing system and where each billing task belongs.

If you have the required permissions, you can access the following billing resources in the Cloud Console:

* [Billing insights](https://docs.coreweave.com/billing/billing-insights.md): View billable resource usage and consumption breakdowns by resource type.

You can also [export usage programmatically with the FOCUS API](https://docs.coreweave.com/billing/focus-export-api.md) (Public Preview), or [find your usage and costs in the Managed Grafana Cost and Usage product zone](https://docs.coreweave.com/observability/managed-grafana/cost-usage/usage-product-zone.md).

If you need help with billing, you can contact the support team at `support@coreweave.com`.
