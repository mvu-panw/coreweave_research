# Create and manage notebooks

> Learn how to create, rename, duplicate, and delete notebooks within your team's overview page, project workspace, or Forge.

Create, rename, duplicate, and delete notebooks within your team's overview page, project workspace, or Forge.

## Create a new notebook

Create a notebook in an existing project or team workspace.

> [tab] Team Overview
>
> 1. Navigate to your team's overview page.
> 2. Select the **Notebooks** tab.
> 3. Select **Create notebook**.
> 4. From the **Project** dropdown, choose the project where you want to create the notebook, or select **Create a new project** to use a new one.

> [tab] Project
>
> 1. Navigate to your project workspace.
> 2. Select **Notebooks** from the project sidebar.
> 3. Select **Create notebook**.

> [tab] Forge
>
> 1. Navigate to Forge.
> 2. Select **Notebooks**.
> 3. Select **Create notebook**.
> 4. Select the project where you want to create the notebook, or select **Create a new project** to use a new one.
> 5. Select **Create**.

## Rename a notebook

Rename an existing notebook from your team's overview page or project workspace.

> [tab] Team Overview
>
> 1. Navigate to your team's overview page.
> 2. Select the **Notebooks** tab.
> 3. Open the **action ()** menu and select **Rename notebook**.
> 4. Enter the new name for your notebook and select **Save**.

> [tab] Project
>
> 1. Navigate to your project workspace.
> 2. Select **Notebooks** from the project sidebar.
> 3. Open the **action ()** menu and select **Rename notebook**.
> 4. Enter the new name for your notebook and select **Save**.

> [tab] Forge
>
> 1. Navigate to Forge.
> 2. Select **Notebooks**.
> 3. Open the **action ()** menu and select **Rename notebook**.

## Duplicate a notebook

Duplicate a notebook to create a copy within the same project or a different project. Forge names the duplicate notebook by prepending `Copy` to the original notebook name.

> [tab] Team Overview
>
> 1. Navigate to your team's overview page.
> 2. Select the **Notebooks** tab.
> 3. Open the **action ()** menu and select **Make a copy**.

> [tab] Project
>
> 1. Navigate to your project workspace.
> 2. Select **Notebooks** from the project sidebar.
> 3. Open the **action ()** menu and select **Make a copy**.

> [tab] Forge
>
> 1. Navigate to Forge.
> 2. Select **Notebooks**.
> 3. Open the **action ()** menu and select **Copy to project**.

## Delete a notebook

Delete a notebook from your team's overview page or project workspace.

> [tab] Team Overview
>
> 1. Navigate to your team's overview page.
> 2. Select the **Notebooks** tab.
> 3. Open the **action ()** menu and select **Delete notebook**.
> 4. Select **Delete notebook**.

> [tab] Project
>
> 1. Navigate to your project workspace.
> 2. Select **Notebooks** from the project sidebar.
> 3. Open the **action ()** menu and select **Delete notebook**.
> 4. Select **Delete notebook**.

> [tab] Forge
>
> 1. Navigate to Forge.
> 2. Select **Notebooks**.
> 3. Open the **action ()** menu and select **Delete notebook**.
