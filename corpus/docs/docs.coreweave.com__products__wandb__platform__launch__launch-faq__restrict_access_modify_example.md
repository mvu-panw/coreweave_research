# How can admins restrict which users have modify access?

Control access to certain queue fields for users who aren't team administrators through [queue config templates](https://docs.coreweave.com/products/wandb/platform/launch/setup-queue-advanced.md). Team administrators define which fields non-admin users can view, and set the editing limits. Only team administrators can create or edit queues.
