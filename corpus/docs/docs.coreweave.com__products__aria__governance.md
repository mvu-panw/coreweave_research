# Governance and security

> Learn how W&B Admins can control how your organization's data is used by W&B's AI features like ARIA.

> [!NOTE]
>
> Available only in [W\&B Multi-tenant Cloud](https://docs.coreweave.com/products/wandb/platform/hosting.md#wb-multi-tenant-cloud).
>
> **Smart features** control options are available for Enterprise and Pro accounts.

[W\&B Admins](https://docs.coreweave.com/products/wandb/platform/hosting/iam/access-management-intro.md#manage-users-and-teams-within-an-organization) can manage access to LLM-powered features and data sharing for performance improvement.

To toggle **Smart features** settings:

1. Log in to Forge.
2. Click the account selector in the upper-right corner. If your organization isn't the current account, select it under **Other accounts**, then open the menu again.
3. In the **Account** section, select **Settings**.
4. Within the **Settings** tab, select **Privacy**.
5. Scroll to the **Smart features** section.
6. Toggle the options according to your preferences. Changes are saved automatically.
