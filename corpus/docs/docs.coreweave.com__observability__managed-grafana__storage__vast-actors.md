# VAST Actors

> Grafana dashboard for monitoring VAST Actor instance NFS bandwidth, IOPS, and read/write statistics

To view the dashboard, go to the [VAST Actors dashboard](https://cks-grafana.coreweave.com/d/ddq5gg6gi5lvke/vast-actors).

> [!NOTE]
>
> For instructions about accessing CoreWeave Grafana dashboards, see [Access and use CoreWeave Grafana dashboards](https://docs.coreweave.com/observability/managed-grafana/access.md).

The VAST Actors dashboard provides metrics related to VAST Actor instances. It contains the following panels:

| Panel | Description |
| - | - |
| **NFS Bandwidth** | Shows overall network bandwidth usage for the NFS service. |
| **NFS Requests per Second** | Shows the rate of NFS requests processed each second. |
| **Metadata IOPS Response Time** | Shows the response time for metadata Input/Output Operations Per Second (IOPS). |
| **Nodes with High RPC Response Times** | Shows Nodes experiencing high response times for Remote Procedure Calls (RPC). |
| **Vast Write Bandwidth per User** | Shows write bandwidth by user. |
| **Vast Write IOPS per User** | Shows write IOPS by user. |
| **Vast Read Bandwidth per User** | Shows read bandwidth by user. |
| **Vast Read IOPS per User** | Shows read IOPS by user. |
| **Replication Bandwidth** | Shows replication bandwidth. |
| **Replication IOPS** | Shows replication IOPS. |
