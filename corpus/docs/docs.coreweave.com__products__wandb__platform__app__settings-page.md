# Settings

Use the Weights & Biases Settings page to customize your individual user profile and manage settings for the teams you belong to. The following sections summarize what you can configure at each level, with links to the detailed pages.

The user settings page supports the following actions:

* [Edit your profile](https://docs.coreweave.com/products/wandb/platform/app/settings-page/user-settings.md#profile), including your profile picture, display name, geographic location, biography information, and email addresses associated with your account.
* [Configure API keys](https://docs.coreweave.com/products/wandb/platform/app/settings-page/user-settings.md#api-keys).
* [Configure alerts](https://docs.coreweave.com/products/wandb/platform/app/settings-page/user-settings.md#alerts) for runs.
* [Delete your account](https://docs.coreweave.com/products/wandb/platform/app/settings-page/user-settings.md#delete-your-account).

For more information, see [User settings](https://docs.coreweave.com/products/wandb/platform/app/settings-page/user-settings.md).

If you belong to one or more teams, the team settings page supports the following actions:

* [Invite or remove members](https://docs.coreweave.com/products/wandb/platform/app/settings-page/teams.md#members) from a team.
* [Manage alerts](https://docs.coreweave.com/products/wandb/platform/app/settings-page/teams.md#alerts) for team runs.
* [Change privacy settings](https://docs.coreweave.com/products/wandb/platform/app/settings-page/teams.md#privacy).
* [View and manage team storage](https://docs.coreweave.com/products/wandb/platform/app/settings-page/teams.md#usage) usage.

For more information about team settings, see [Team settings](https://docs.coreweave.com/products/wandb/platform/app/settings-page/teams.md).
