# Annotate conversation turns

> Add reactions and notes to conversation turns to record what your team noticed while reviewing traces.

CoreWeave Agent Lens lets you annotate individual turns while you review a conversation. A reaction is a quick emoji verdict, and a note is free text for anything that needs more than an emoji. Both are visible to everyone with access to the project, so a reviewer can flag a turn and a teammate can pick it up later without a separate tracking sheet.

Annotations attach to a turn, one user message and the agent's complete response. You cannot annotate a whole conversation or an individual span.

The page covers how to add reactions and notes.

## Open a turn

To annotate a turn, first open the conversation that contains it:

1. Navigate to [CoreWeave Forge](https://forge.coreweave.com) and select Agent Lens from the product menu.
2. Select your project. Agent Lens opens the project you used most recently. To switch projects, use the project selector at the top of the side menu.
3. In the Agent Lens side menu, select **Conversations**.
4. Select a conversation to open it. The **Thread** tab shows each turn in order.

The header of each turn shows the annotation controls: **Add reaction**, **Add note**, and **Add tag**. See [Create a custom tag](https://docs.coreweave.com/products/agent-lens/tags/create-tag.md) for more information about tagging.

## Add a reaction

A reaction records a one-glance verdict on a turn, such as a thumbs up for a response you want more of or a warning sign for one that needs attention.

1. In the turn header, select **Add reaction**. The **Reactions** popover opens.
2. In the popover, select the add-emoji button, and then pick an emoji.

The emoji appears in the turn header with a count. When more than one person reacts, reactions are grouped by emoji and the count shows how many people used each one. Hover the control to see the full list.

To remove a reaction you added, select it again.

## Add a note

A note is free-form text attached to a turn, for example why a response was wrong, what the expected answer was, or a link to a ticket.

1. In the turn header, select **Add note**. The **Notes** popover opens.
2. Type your note in the **Add a note** field.
3. Select the submit button.

Each note shows the author's name and avatar and when it was written. A turn can carry any number of notes from any number of people. Notes cannot be edited or deleted in Agent Lens after you submit them.
