This page describes how to use Weights & Biases with [OpenAI Gym](https://github.com/openai/gym) to automatically capture videos of your reinforcement learning environments. You can then review agent behavior alongside your experiment metrics in Weights & Biases.

If you're using OpenAI Gym, Weights & Biases automatically logs videos of your environment generated by `gym.wrappers.Monitor`. To enable this, set the `monitor_gym` keyword argument to [`wandb.init()`](https://docs.coreweave.com/products/wandb/ref/python/functions/init) to `True`, or call `wandb.gym.monitor()`.

The gym integration is lightweight. It [looks at the name of the video file](https://github.com/wandb/wandb/blob/master/wandb/integration/gym/__init__.py#L15) being logged from `gym` and names it after that, or falls back to `"videos"` if it doesn't find a match. If you want more control, you can manually [log a video](https://docs.coreweave.com/products/wandb/track/log/media.md).

The [OpenRL Benchmark](https://wandb.me/openrl-benchmark-report) by [CleanRL](https://github.com/vwxyzjn/cleanrl) uses this integration for its OpenAI Gym examples. You can find source code (including [the code used for specific runs](https://forge.coreweave.com/wandb/cleanrl/cleanrl.benchmark/runs/2jrqfugg/code?workspace=user-costa-huang)) that demonstrates how to use gym with Weights & Biases.
