# CoreWeave Omni

> Run the CoreWeave Cloud Platform in your data center with CoreWeave-managed operations and full hardware control

CoreWeave Omni is a cloud-as-a-service model. CoreWeave deploys and operates the full CoreWeave cloud stack inside your data center. You keep ownership of the facility and hardware. CoreWeave delivers a managed region, the CoreWeave Cloud Platform, and day-to-day operational management.

## What CoreWeave provides

CoreWeave Omni includes the following:

* **Managed cloud region:** The CoreWeave cloud stack runs in your data center as a dedicated region.
* **CoreWeave Cloud Platform:** Kubernetes orchestration, the control plane, networking, storage, and observability.
* **Operational management:** CoreWeave runs the environment. You own the data center facility and the hardware.

## The Omni stack

Omni is organized as layers, from infrastructure through AI development:

| Layer | Role |
| - | - |
| **Foundational infrastructure** | Base compute, power, and facilities integration. |
| **Data and storage** | Data services and storage aligned with CoreWeave patterns. |
| **Infrastructure control** | Provisioning and lifecycle for underlying resources. |
| **Runtime acceleration** | Performance-oriented runtime for demanding workloads. |
| **Model and agent development** | Environments for models, agents, and supporting tools. |

**Mission Control** spans the stack with shared platform capabilities: security, talent services, and observability.
