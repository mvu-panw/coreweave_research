> [!NOTE]
>
> This table doesn't map SUNK releases to CKS Kubernetes versions. CKS clusters on Kubernetes v1.35 and later require cgroup v2 on all nodes. For the control group version of each supported Kubernetes release, see [Cluster components](https://docs.coreweave.com/products/cks/reference/cluster-components.md). To set the cgroup version in SUNK, see [Manage resource binding with task plugins](https://docs.coreweave.com/products/sunk/optimize_workloads/task-plugins.md#configure-the-task-cgroup-plugin).
