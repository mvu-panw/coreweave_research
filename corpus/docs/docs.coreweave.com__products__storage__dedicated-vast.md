# Dedicated VAST Storage

> Single-tenant VAST clusters co-located with CoreWeave GPUs for physical isolation and petabyte-scale storage

Dedicated VAST Storage gives you an exclusive VAST cluster in a CoreWeave data center alongside your GPU workloads. Each cluster is physically isolated to a single tenant. You get direct VAST Management System (VMS) access, multi-protocol support (NFS, S3, NVMe/TCP, and SQL), and the full VAST feature set, including VAST Catalog, DataBase, DataEngine, and Global Access.

Dedicated VAST is a capacity-reserved product that CoreWeave provisions for you. [Contact Sales](https://www.coreweave.com/contact-us) to size and provision a cluster.
