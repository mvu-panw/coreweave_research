# About inference on CKS

> Run self-managed inference workloads on CoreWeave Kubernetes Service

Inference on CKS gives you full control over your inference deployment stack using CoreWeave Kubernetes Service. Deploy inference runtimes, configure networking, and manage scaling directly through Kubernetes resources on CoreWeave GPU infrastructure.

The following tutorials walk through deploying common inference runtimes on CKS:

* [Deploy Red Hat AI inference and llm-d on CoreWeave Kubernetes Service (CKS)](https://docs.coreweave.com/products/cks/tutorials/redhat-inference.md)
* [Deploy NVIDIA Dynamo on CKS](https://docs.coreweave.com/products/cks/tutorials/dynamo-inference.md)
* [Deploy vLLM for inference](https://docs.coreweave.com/products/cks/tutorials/deploy-vllm-inference.md)
