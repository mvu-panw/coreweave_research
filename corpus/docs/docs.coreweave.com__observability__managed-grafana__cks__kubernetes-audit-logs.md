# Kubernetes Audit Logs

> Grafana dashboard for viewing Kubernetes audit logs for security and troubleshooting in CKS

To view the dashboard, go to the [Kubernetes Audit Logs dashboard](https://cks-grafana.coreweave.com/d/k8s-audit-logs/kubernetes-audit-logs).

> [!NOTE]
>
> For instructions about accessing CoreWeave Grafana dashboards, see [Access and use CoreWeave Grafana dashboards](https://docs.coreweave.com/observability/managed-grafana/access.md).

The Kubernetes Audit Logs dashboard provides detailed information about cluster events and supports security, auditing, and troubleshooting.

Use column filters to query for specific logs.
