# Get Started with Weights & Biases

> Choose a quickstart for tracking ML experiments or tracing LLM applications with Weights & Biases

Weights & Biases tracks, visualizes, and compares your machine learning experiments. It includes W\&B Weave, which traces and evaluates LLM applications. Choose the quickstart that matches what you're building.

| If you're | Start with | Key features |
| - | - | - |
| Training or fine-tuning ML models | [Track ML experiments](#track-ml-experiments) | Experiment tracking, hyperparameter optimization, artifacts, visualizations |
| Tracing and evaluating existing models and applications | [Trace LLM applications](#trace-llm-applications) | Tracing, prompt management, evaluation, cost tracking for production AI apps |
