# Public IPv4

> Learn about public IPv4 addresses for hosting publicly accessible services on CoreWeave Cloud

Public IPv4 (Internet Protocol version 4 (IPv4) is one of the core protocols that enables the Internet.) addresses are available for all CoreWeave Cloud instances. These addresses are routable on the public Internet and can host public services, which makes them suitable for applications that need to be reachable from anywhere.

## More information

To learn how to expose a service using public IPv4 addresses, including how LoadBalancers work, how the public IPs are assigned, and how DNS names are created, see [How to: Expose a Service](https://docs.coreweave.com/products/networking/ingress-service/expose-service-dns.md).

## Billing

For periods of use less than one month, the public IP address charge is prorated by the minute. If a public IP address is assigned to a Service, but the Service isn't running, billing continues to accrue for the assigned address.

See [CoreWeave Cloud Pricing](https://www.coreweave.com/pricing) for details.
