# About Object Storage APIs

> Introduction to the S3-compatible API and the AI Object Storage API for identity and access management

CoreWeave AI Object Storage is an S3-compatible object storage solution with two APIs:

* The [**S3-compatible API**](https://docs.coreweave.com/products/storage/object-storage/reference/object-storage-s3.md) handles storage operations: creating buckets, uploading objects, managing data, and all standard S3-compatible workflows.
* The [**AI Object Storage API**](https://docs.coreweave.com/products/storage/object-storage/reference/object-storage-api-ref.md) handles identity and access management: creating access keys, setting organization policies, and administrative tasks not covered by the S3 standard.
