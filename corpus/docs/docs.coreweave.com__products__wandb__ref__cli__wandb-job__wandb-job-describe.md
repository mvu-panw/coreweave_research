# wandb job describe

[View source](https://github.com/wandb/wandb/blob/v0.31.0/wandb/cli/cli.py#L2140)

## Usage

```bash theme={"system"}
describe [OPTIONS] JOB
```

## Description

Describe a launch job. Provide the launch job in the form
of: entity/project/job-name:alias-or-version.

## Arguments

| Name | Default | Type |
| - | - | - |
| `job` | STR | True |
