# SUNK reference

> Container images, custom resource fields, configuration parameters, and version mappings for SUNK.

These pages describe the Slurm container images that SUNK builds, the SunkCluster custom resource, the parameters for the SUNK operator, Slurm, and Slurm login Helm charts and for SCIM, and the Slurm version that corresponds to each SUNK release.

>

> [card] [SunkCluster reference](https://docs.coreweave.com/products/sunk/reference/sunkcluster-reference.md)
>
> Reference parameters for the SunkCluster custom resource that defines a SUNK Self-Service cluster.

> [card] [Slurm images](https://docs.coreweave.com/products/sunk/reference/slurm-images.md)
>
> Reference for SUNK-built Slurm container images, including base and extras variants with supported CUDA versions.

> [card] [Slurm parameter reference](https://docs.coreweave.com/products/sunk/reference/slurm-parameters.md)
>
> Complete parameter reference for the Slurm Helm chart, including accounting, compute, and deployment settings.

> [card] [Slurm login parameter reference](https://docs.coreweave.com/products/sunk/reference/slurm-login-parameters.md)
>
> Complete parameter reference for the Slurm login Helm chart, including directory cache and affinity settings.

>
> Mapping table between SUNK release versions and their corresponding Slurm versions.

> Complete reference of configurable SCIM parameters for SUNK user identity management.
