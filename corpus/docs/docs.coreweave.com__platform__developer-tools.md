# Developer tools

> Automate CoreWeave with agents, the CLI, Terraform, and REST APIs.

CoreWeave provides tools for working with your infrastructure from a terminal, a script, a CI pipeline, or an AI agent. Choose the tool that fits how you work. You can combine them: for example, define infrastructure in Terraform and investigate it with Mission Control.

## Choose a tool

> [card] [CoreWeave Skills](https://docs.coreweave.com/platform/coreweave-skills.md)
>
> Agent Skills that let Claude Code and other compatible agents carry out CoreWeave workflows for you.

> [card] [Mission Control Agent](https://docs.coreweave.com/observability/mission-control-agent.md)
>
> Investigate your environment through a conversational interface in the Cloud Console.

> [card] [Mission Control MCP](https://docs.coreweave.com/observability/mission-control-mcp.md)
>
> Connect MCP-compatible AI clients to CoreWeave observability data and supported write actions.

> [card] [CoreWeave Intelligent CLI](https://github.com/coreweave/cwic)
>
> Manage clusters, Nodes, and other resources from the command line with `cwic`.

> [card] [Terraform provider](https://docs.coreweave.com/platform/terraform.md)
>
> Manage CoreWeave Infrastructure as code.

> [card] [REST APIs](https://docs.coreweave.com/reference-home.md#infrastructure)
>
> Browse the API references for CoreWeave Infrastructure.
