# Agent Lens SDK reference

> Reference for the Python and TypeScript SDKs that send agent traces to Agent Lens.

Choose the reference for the language your agent is written in. Both SDKs send traces to Agent Lens.

> [card] [Python SDK](https://docs.coreweave.com/products/agent-lens/reference/python-sdk.md)
>
> Set up tracing and record conversations, turns, LLM calls, and tool calls from Python.

> [card] [TypeScript SDK](https://docs.coreweave.com/products/agent-lens/reference/typescript-sdk.md)
>
> Use the tracing and provider integration APIs in `@coreweave/forge-sdk`.
