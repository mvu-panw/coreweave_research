Transcript

Building a capable web agent is only half the challenge; the harder problem is knowing whether it is working well in production. This talk explores how Parallel Web Systems measures quality across customer-specific use cases, monitors agent behavior, and automatically triages failures at scale. We'll also discuss how we evaluate complex research tasks where correctness is nuanced, outputs are subjective, and traditional benchmarks fail to capture what customers actually value.
Speakers: Pranay Reddy Samala, Member of Technical Staff, Parallel Web Systems
