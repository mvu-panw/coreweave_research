Run agent sandboxes, reinforcement learning, and data pipelines on bare-metal CPUs with NVIDIA Vera, AMD EPYC™, and Intel® Xeon® processors

### Agent sandboxes

Run code, use tools, and evaluate results in isolated environments that start fast and run side by side at scale.

### Reinforcement learning

Generate the experience models learn from, with rollouts running in parallel, reward functions running in isolated sandboxes that snapshot and resume, and results feeding back into training.

### Data pipelines

Preprocess, analyze, and move data fast enough that GPUs stay busy instead of waiting on the next batch.
Explore storage

### Run on bare metal

Skip the virtualization layer and run sandboxes on single-tenant hardware, isolated at the hardware level, with none of the overhead that comes with it.

### Built for the sandbox

NVIDIA Vera's Spatial Multithreading gives each thread its own dedicated share of the processor, so every sandbox performs at full load.

### Scale on a non-blocking network

Our multi-plane network keeps traffic moving as sandboxes scale, while BlueField DPUs enforce tenant isolation and handle networking so your sandboxes keep their CPU cores.

### NVIDIA Vera

- The first CPU built for AI agents, with up to 1.8x faster agentic sandbox execution
- 88 custom Olympus cores designed for the branch-heavy, memory-bound work agents generate
- Supporting up to 400Gb/s of network bandwidth per node
- Equipped with NVIDIA BlueField DPUs

### AMD EPYC™ 9005 Series

- Available in high-performance, high-core, and general-purpose configurations
- Up to 86% better gen-to-gen performance compared to general-purpose servers with AMD EPYC 9004 Series CPUs
- Supporting up to 1.5TB of memory per system
- Equipped with NVIDIA BlueField DPUs

- Up to 28% better performance than CoreWeave Intel Xeon 3rd Generation servers
